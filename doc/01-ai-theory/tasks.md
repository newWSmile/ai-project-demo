# 第 3～5 周：AI 与大模型基础理论

## 阶段目标

达到“能解释、能实验、能为工程选型服务”的理论水平，不以训练基础大模型为目标。

## 第 3 周：机器学习和必要数学直觉

- [ ] 理解监督学习、无监督学习、强化学习的差异。
- [ ] 理解训练集、验证集、测试集和数据泄漏。
- [ ] 理解损失函数、梯度下降、学习率、过拟合和正则化。
- [ ] 复习向量、矩阵、点积、范数和余弦相似度。
- [ ] 理解概率、条件概率、Softmax 和交叉熵的直觉。
- [ ] 用 Python/Notebook 计算并可视化若干文本向量的余弦相似度。
- [ ] 写出“相似度高不等于答案正确”的实验结论。

## 第 4 周：Transformer 与 LLM

- [ ] 理解 Tokenizer 和 Token 数量对成本、截断的影响。
- [ ] 理解 Embedding 的用途和限制。
- [ ] 画出 Transformer 的输入、Attention、前馈网络和输出流程。
- [ ] 理解 Query、Key、Value 和 Self-Attention 的直觉。
- [ ] 理解位置编码为什么必要。
- [ ] 理解预训练、指令微调和推理之间的区别。
- [ ] 理解上下文窗口、KV Cache、量化和推理延迟。
- [ ] 完成 Temperature、Top-P、Max Tokens 对输出影响的对比实验。

## 第 5 周：模型定制与技术选型

- [ ] 理解 SFT、LoRA、RLHF、DPO 的目标和大致流程。
- [ ] 理解幻觉产生的原因和不可完全消除的性质。
- [ ] 对比 Prompt、RAG、微调、Tool Calling 的适用场景。
- [ ] 对同一任务至少测试两个模型，比较质量、延迟和成本。
- [ ] 编写一份模型选型记录：业务约束、数据敏感性、质量、延迟、成本。
- [ ] 说明为什么当前 Demo 不需要预训练或微调大模型。

## 完成标准

- [ ] 能在不看资料的情况下画出简化 Transformer 流程。
- [ ] 能解释 Embedding、Attention、RAG 和微调之间的关系。
- [ ] 能依据业务问题选择 Prompt、RAG、微调或工具调用，而不是套用框架。
- [ ] 保存至少 3 个可重复运行的 Notebook/实验。
